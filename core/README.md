# Core

W02의 `project/`는 UI와 독립된 사용자 루트·설정 초기화/열기/저장 계약이다.

W05–W10의 `content/`/`project/`는 콘텐츠·트리와 안전한 변경/복구를 제공한다. W11의 `markdown/`은 앵커·목차·각주·정화 HTML을, W12의 `url/`은 실효 공개 ID/앵커→접두 URL과 과거 경로→현재 대상 정적 리디렉션을 제공한다. W13의 `media/`는 공개 자산을 검증·선별하고 W14의 `site/`가 공개 페이지/인덱스를 만든다. W15–W16의 `build/`는 입력 스냅샷·임시 출력·누출/파일 집합 감사·실패 복원 뒤 `dist/`에 반영한다.
