# Core

W02의 `project/`는 UI와 독립된 사용자 루트·설정 초기화/열기/저장 계약이다.

W05의 `content/`는 콘텐츠 스키마와 읽기 전용 프로젝트 인덱스를 제공한다. W06의 `project/`는 예약 기본 루트와 안전 저장/복구를 제공한다. W07의 `content/visibility`는 자기/모든 조상 상태·필수 공개 차단·개요/공개 자손이 없는 구조를 하나의 판정과 이유 코드로 반환한다. W08의 `content/crud`와 `content/references`는 네 상위 유형의 초안 생성·ID 기반 조회/수정·영향 확인 후 삭제/복원과 관련 콘텐츠/미디어 참조 진단을 제공한다. 경론 내부 트리 변경·주소 변환과 빌드는 후속 작업에서 확장한다.
