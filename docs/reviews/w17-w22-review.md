## 검증 근거

- 단위/통합: 트리 격리·조상·이전다음·대응 선택/원본 링크, 유형별 생성·이스케이프·이야기 출처/각색/날짜, 공개 검색/출력 감사, 비공개 재빌드 제거.
- Chromium: 홈→분류→경론→영역→문서, 새로고침/접두사/현재 위치, 목차·각주/직접 해시/참조 복귀/인쇄 이벤트 DOM 복원, 390px 모바일 트리 기본 닫힘·Escape/패널 초점, 검색/404.
- 정적 빌드: 원본이 비어 있는 기본 project의 오류/경고 없는 빌드. 실제 콘텐츠를 대신하는 운영 샘플을 추가하지 않았다.
- 실행 환경: Node 24.22.1/npm 11.14.1. 기준 Node 24.x 범위이며 .node-version의 패치 버전은 변경하지 않았다.
- 최종 회귀: Vitest 131건, Playwright 5건, 환경 검사와 공개 빌드(15개 파일·오류/경고 0)를 통과했다.

## 남은 검증

R04/R06과 W27/W32에서 실제 경론 장문·큰 트리·한자/팔리어 글꼴, 실제 Safari/모바일 기기·터치, 인쇄 결과의 실제 페이지 레이아웃, 성능 예산을 확인해야 한다. 현재 Chromium 검사와 인쇄 이벤트 DOM 검증을 해당 수동 검증 완료로 해석하지 않는다. Pages 호스팅의 직접 URL/404는 W31 실제 배포 검증 대상이다.
