# 보리도 화면·상호작용 명세

- 통합 개정 1.0 · 2026-10-29 · 현재 개발 기준
- 담당: 공개 사이트·경론 읽기·로컬 편집기의 화면과 상태·접근성.
- 모델·공개 계산·주소·각주 데이터는 [콘텐츠 명세](content-spec.md), 파일 변경·보안·배포 실행은 [기술 명세](technical-spec.md)를 따른다. 이 문서에서 같은 계산을 다시 정의하지 않는다.

<a id="design"></a>
## 1. 디자인 기반과 공통 요소

Basecoat 기본 Vega를 초기 스타일로 사용한다. Basecoat 파일을 수정하지 않고 보리도 공통 토큰/타이포그래피/레이아웃과 전용 컴포넌트 CSS를 분리한다. CSS와 필요한 JS는 로컬 제공하며 필수 기능이 CDN에 의존하지 않는다. 여러 스타일 팩을 섞거나 전체 JS를 무조건 포함하지 않는다.

2026-10-29 사용자 지시에 따라 OL 프로젝트의 단순한 shadcn/ui 계열 표현을 참고하되 코드를 복제하지 않고 설계 원칙만 수용한다. 기본 팔레트는 검정·흰색·중립 회색이며, 주 강조색은 황금색 `#f0b100`, 보조 강조색은 연두색 `#00c951`이다. 황금색은 주요 행동·선택·강조, 연두색은 성공·정상 상태처럼 제한된 의미에 사용한다. 색만으로 상태를 구분하지 않고 텍스트·형태를 함께 제공한다.

공통 토큰은 배경/표면/경계/잉크/약한 텍스트, 6·8·14px 반경, 낮은 그림자, 산세리프 UI/모노 글꼴, 4px 기반 간격으로 분리한다. 얇은 경계, 낮은 장식 밀도, 짧은 120–160ms 상호작용, 1200px 일반 컨테이너와 720px 읽기 폭을 초기 참고값으로 삼는다. 공개 독서 화면의 실제 본문 폭·글꼴·전환점은 R04에서 한글·한자·팔리어·긴 각주로 검증한 뒤 확정한다. OL의 브랜드 문구·콘텐츠별 배경 패턴·카드 구성은 보리도 요구가 생기기 전에는 가져오지 않는다.

GitHub에서 참조하는 것은 계층 탐색·파일/폴더 구분·현재 위치 표시다. 그 화면을 복제하거나 공개 독서의 기본 화면으로 GitHub 파일 탐색기를 사용하지 않는다. 밝고 차분한 문서 중심 표현, 명확한 버튼/링크, 아이콘과 텍스트 레이블을 사용한다.

UI와 본문 글꼴/간격은 역할을 구분한다. 우선 로컬 시스템 대체 글꼴로 한글·한자·팔리어/산스크리트어 표시를 확인한다. 글꼴을 포함할 때에는 사용 조건과 오프라인 배포를 확인한다. 인용·서지·각주를 구분하되 지나치게 작게 만들지 않는다.

### 1.1 치수와 검증 상태

|항목|현재 상태|
|---|---|
|데스크톱 자료 트리|240px, 기본 열림, 현재 자료의 트리만 표시 — 확정|
|우측 패널|기본 닫힘, 넓은 화면 Push·좁으면 오버레이 — 확정|
|본문 최대 너비/우측 패널|약 800px/300px — 실제 경론 검증용 시작값|
|줄 간격|약 1.9 — 검증용 시작값|
|본문 여백/모바일 드로어 폭/애니메이션|실제 최소 본문 폭·긴 제목/각주로 검증(R04)|
|반응형 전환점|콘텐츠 공간을 기준으로 실측. 이전 1200/900/640px는 영구 기준이 아님|

트리 폭을 드래그로 조절하는 기능·다중 스타일 팩·현재 목차 위치 자동 강조는 초기 필수가 아니다. 검증 결과를 기록하지 않고 시험값을 최종 수치로 바꾸지 않는다.

## 2. 공개 사이트 공통과 페이지

공통 구조는 헤더→페이지 제목/경로→콘텐츠→푸터다. 헤더에는 사이트명/로고, 홈·경론·이야기·블로그·소개/일반 페이지와 검색 진입점을 둔다. 로고는 홈으로 연결하고 현재 메뉴/문서에 적절한 `aria-current` 등 상태를 제공한다. 메뉴에 넣을 일반 페이지가 없으면 빈 링크를 만들지 않는다.

breadcrumbs는 실제 존재하고 공개 가능한 조상만 연결한다. 현재 위치는 링크와 구분하고, 긴 경로는 작은 화면에서 축약할 수 있다. 푸터는 소개·라이선스·운영 정보를 간결하게 표시한다. 공개할 수 없는 정보와 숨겨진 데이터의 판단은 Core 결과를 사용한다.

|페이지|표시와 동작|
|---|---|
|홈|짧은 소개, 경론/이야기/블로그/소개 진입. 최근 콘텐츠는 있을 때만 표시|
|경론 분류|설정 데이터의 분류명·순서·선택 설명/문헌 수. 하드코딩하지 않음|
|분류별 경론|공개 문헌 제목 중심 목록, 있는 서지만 표시. 선택하면 경론 개요|
|경론 개요|문헌 설명·서지·분류, 존재하는 자료 영역 진입과 구조 탐색|
|영역/구조 페이지|개요가 있으면 표시하고 공개 하위 목록/트리 제공. 자동으로 임의 본문 선택하지 않음|
|이야기 목록/본문|제목·선택 이미지/설명·본문·출처/각색 정보. 이미지 없어도 자연스럽게 유지|
|블로그 목록/본문|게시일·선택 작성자/태그·요약·본문. 날짜/정렬은 콘텐츠 명세 사용|
|일반 페이지|제목·본문·필요 시 목차, 허용한 템플릿. 경론 트리는 자동 표시하지 않음|

모든 페이지는 실제 URL 링크로 이동한다. 전체 페이지 전환으로 구현할 수 있으며, 직접 입력·새로고침·뒤로/앞으로를 지원한다. 공개 URL·자산·앵커는 프로젝트 접두사와 사용자 지정 도메인을 고려한다.

## 3. 경론 읽기 화면

데스크톱 기본은 공통 헤더/경로 아래 왼쪽 240px 자료 트리와 중앙 문서 제목·서지·도구모음·본문이다. 우측 패널은 닫힌 상태로 시작한다. 본문은 가용 공간 안에서 최대 너비를 적용하고 읽기 적합하게 정렬한다. 헤더/서지로 불필요한 세로 공간을 소비하지 않는다.

### 3.1 자료 트리

- 현재 선택 영역의 트리만 보여주고 번역/원문/연구를 하나의 트리로 합치지 않는다.
- 구조와 본문을 시각적으로 구분하고 펼침 컨트롤과 이동 링크를 구분한다. 개요 없는 구조 항목도 공개 자식 탐색 페이지로 이동할 수 있다.
- 현재 문서를 강조하고 해당 조상을 자동으로 펼친다. 모든 하위 항목을 무조건 펼치지 않는다.
- 깊이를 임의 제한하지 않고 들여쓰기만 무한히 늘리지 않는다. 선·간격/표시로 계층을 이해할 수 있게 한다.
- 트리는 독립 스크롤을 가지며 긴 제목과 낮은 높이에서도 현재 위치에 접근할 수 있다. 말줄임 시 전체 제목을 접근 가능하게 확인할 수 있어야 한다.
- 문서 전환 후 URL·breadcrumbs·제목/서지·본문·현재 항목·목차/각주 데이터가 같은 문서를 가리켜야 한다.

### 3.2 제목·도구모음·문서 이동

제목과 필요한 상위 경론명·영역·저자/역자·판본/출전만 표시한다. 없는 서지로 빈 프레임을 만들지 않는다. 본문 제목은 콘텐츠 명세의 규칙을 적용하고 원문을 조용히 삭제하지 않는다.

도구모음에는 자료 트리 표시/숨김(특히 모바일), 제목이 있는 경우 목차, 각주가 있는 경우 각주, 공개 자료가 있는 경우 자료 전환을 둔다. 이전/다음은 상단이나 문서 끝의 일관된 탐색 위치에 제공한다. 버튼은 아이콘+텍스트와 상태/접근성 이름을 가진다.

이전/다음은 현재 영역의 공개 트리를 깊이 우선 순서로 보아 본문 문서만 대상으로 한다. 구조 개요와 비공개 자료는 건너뛰며 첫/마지막에서는 해당 링크를 숨긴다. 자료 전환은 명시적 대응 문서가 있으면 그 문서로, 없으면 목표 영역 개요/목록으로 간다. 여러 대응이 있으면 선택지를 보여주고 임의로 첫 문서를 추정하지 않는다. 공개 자료가 없는 영역은 연결하지 않는다.

GitHub 원본/디렉터리/이력 링크는 `biwoom/borido` 안의 실제 `project/` 원본 위치와 `public_links` 허용을 확인한 경우만 제공한다. 같은 저장소라는 이유로 초안/비공개 파일 링크를 만들지 않는다. 복사·Markdown 다운로드·글자 크기 조정과 인쇄 버튼은 후속이며, 기본 인쇄 CSS는 초기 포함한다.

## 4. 목차·각주 패널과 정적 접근

### 4.1 패널 상태

|현재 상태|행동|결과|
|---|---|---|
|닫힘|목차/각주 선택|선택 모드 열기|
|목차 열림|목차 재선택/닫기/Escape|닫힘|
|각주 열림|각주 재선택/닫기/Escape|닫힘|
|한 모드 열림|다른 모드 선택|같은 패널에서 내용 전환|
|일반 문서 진입/새 문서 이동|초기화|우측 닫힘|
|각주 해시 직접 진입|대상 각주 존재|각주를 보이게 함 — 기본 닫힘의 예외|

우측 패널 상단에 제목·모드 전환·닫기를 둔다. 없는 목차/각주 모드는 제공하지 않는다. 넓은 화면은 본문을 밀어 공간을 확보하고 좌측 트리 폭을 유지한다. 본문 최소 폭이 부족하면 오버레이/모바일형으로 전환한다. 패널 열기/닫기는 문서 재로딩이나 문서 URL 변경을 일으키지 않는다. 목차/각주 위치 이동의 해시 변경은 별개다.

### 4.2 목차

현재 Markdown 제목의 순서/계층을 그대로 반영하고 임의 항목을 만들지 않는다. 선택 시 같은 앵커로 이동하며 필요 시 URL 해시를 갱신한다. 제목이 없으면 버튼/빈 패널을 제공하지 않는다. 현재 읽는 목차 강조는 후속 보조 기능이다.

### 4.3 각주

정적 HTML에는 하단 각주·참조·돌아가기 링크를 제공한다. JS가 켜지면 같은 각주 DOM을 우측 패널로 옮겨 이용한다. 하단/패널용 DOM을 복제해 ID를 중복 생성하지 않는다. JS가 없으면 하단 각주로 기본 접근한다.

본문 참조를 선택하면 각주 모드 열기→대상 항목이 보이게 이동/강조→해당 참조로 돌아가기가 가능해야 한다. 반복 참조는 사용자가 선택했던 정확한 참조로 돌아간다. 직접 해시 진입에서도 숨겨진 각주 때문에 내용 접근이 막히지 않아야 한다. 긴 역주·여러 문단·표/이미지는 패널 내부에서 전체를 읽으며 가로 넘침을 억제한다.

본문은 주 스크롤, 트리와 패널은 자체 스크롤이다. 단순 패널 전환/닫기는 읽던 위치를 불필요하게 초기화하지 않는다. 목차/각주 선택으로 의도적으로 이동하는 경우와 구분한다. 인쇄 시 패널 상태와 무관하게 본문·각주가 나오고 탐색 도구/드로어는 숨긴다.

## 5. 모바일·접근성

모바일은 본문 중심, 자료 트리/보조 패널은 기본 닫힘이다. 트리는 왼쪽 드로어, 목차·각주는 오른쪽 드로어다. 한쪽을 열면 다른 쪽은 닫는다. 드로어가 열린 동안 본문은 배경으로 유지한다.

- 트리 항목 선택 후 문서 이동과 드로어 닫기. 닫기 버튼·바깥 영역·Escape로 닫기.
- 열 때 초점을 해당 영역으로, 닫을 때 연 컨트롤로 복귀. 참조 왕복/페이지 이동처럼 명확한 목표가 있으면 그 위치를 우선한다.
- 키보드로 메뉴·트리·도구·탭·닫기·본문 링크를 조작하고 현재/펼침/선택 상태를 전달한다. 초점이 화면 뒤로 빠지거나 닫힌 패널에 남지 않도록 한다.
- 아이콘만 남기기보다 레이블을 유지하고 간격/배치를 조정한다. 터치 영역·긴 제목·줄바꿈·낮은 화면 높이를 확인한다.
- 공통 모바일 메뉴는 공간에 맞춰 접으며 문서 트리와 구분한다. JS가 없더라도 정적 본문과 주요 페이지/각주 링크에 접근할 수 있다.

지원 전환점 전후·좁은 화면·터치·키보드·JS 비활성을 W20에서 확인한다. 실제 Safari/모바일 확인은 엔진 에뮬레이션 통과와 구분해 기록한다.

## 6. 검색·예외 상태

헤더 검색 진입점과 검색 페이지를 제공한다. 결과는 제목·유형·맥락·선택 설명과 실제 문서 URL로 표시한다. 검색 동작/대상은 [검색 데이터 계약](content-spec.md#search)을 따른다. 서버 검색을 요구하지 않으며 입력 없음·일치 없음·인덱스 로드 오류를 구별해 안내한다. 고급 필터/검색 문법은 초기 제외한다.

존재하지 않는 URL은 정적 404 안내와 홈/콘텐츠 진입 링크를 제공한다. 빈 목록·빈 자료 영역·목차/각주 없음·대표 이미지/서지 없음·선택 메뉴 없음은 빈 카드/버튼을 만들지 않는다. 누락 이미지는 레이아웃을 무너뜨리지 않게 표시하되 원본 문제는 빌드 검증에서 진단한다. 비공개 콘텐츠의 존재/제목을 공개 오류 안내로 노출하지 않는다.

## 7. 로컬 편집기

### 7.1 시작과 관리 화면

상단은 사이트명·저장 상태·미리보기·빌드·배포, 왼쪽은 설정·경론·이야기·블로그·일반 페이지·미디어, 중앙은 목록/편집/설정 작업 영역이다. 복잡한 대시보드·분석 화면은 추가하지 않는다.

인자 없는 실행은 예약된 `project/`에서 생성/기존 열기를 구분하고, 명시 인자가 있으면 외부 프로젝트를 연다. 경로 존재·권한·다른 파일/프로젝트를 확인하고 사전 경고/중단 없이 덮어쓰지 않는다. 사이트명·설명·언어·작성자·라이선스·시간대·공개 URL을 입력/확인한다. GitHub 인증은 건너뛰고 나중에 설정할 수 있다. 초기화 후 경론 목록, 이후 실행에서는 기존 프로젝트를 연다.

설정은 사이트·콘텐츠 편집 정책·디자인 기준/시스템 정보·`biwoom/borido` 원본/Actions Pages 역할·인증 상태·백업/복구를 다룬다. 임의 외부 프로그램 설치·원격 저장소 생성은 수행하지 않는다. 프로젝트 루트 변경은 앱 종료 후 이동/재열기 안내를 제공하며 UI 요청만으로 허용 루트를 바꾸지 않는다.

### 7.2 콘텐츠와 트리 관리

네 유형 목록·검색/상태/분류 필터·생성·메타데이터/본문 편집·공개 상태를 제공한다. 경론은 서지/분류·세 영역·구조/본문/개요·순서/이동을 관리한다. 제목/ID/slug/파일 위치의 역할을 구분해 설명하고 자동 ID는 일반 편집에서 바꾸지 않는다.

이동/삭제/정렬은 대상·하위·참조·미디어·주소 변경 영향을 확인하고 명시 실행한다. 삭제 취소·참조 목록 확인·참조 수정 후 삭제와 복구 경로를 제공한다. 드래그 조작만 요구하지 않고 순서/이동 입력으로도 수행할 수 있게 한다.

이야기는 출처/각색/이미지, 블로그는 게시일/태그, 페이지는 메뉴/허용 템플릿을 유형에 맞게 편집한다. 범용 JSON 편집기나 임의 스키마 확장 UI를 만들지 않는다. 미검증 분류·비공개 조상·잘못된 공개 참조는 위치/원인을 안내하고 자동 공개/수정하지 않는다.

### 7.3 저장 상태와 미리보기

|상태|표시/동작|
|---|---|
|미저장 변경|저장 필요 표시. 이동/닫기 전 확인|
|저장 중|진행 표시. 같은 저장 요청을 중복 실행하지 않음|
|저장 완료|실제 파일 반영 확인 후 표시|
|저장 실패|원인/재시도 안내, 편집 버퍼 유지|
|외부 변경/리비전 충돌|덮어쓰기 중단, 비교/재열기 안내. 자동 병합하지 않음|

초기는 명시 저장 버튼과 Cmd/Ctrl+S를 지원한다. 자동 저장과 미저장 입력의 주기적 복구 저장은 후속이다. 저장 실패 보호를 브라우저 강제 종료 전 모든 입력 복구 보장으로 표현하지 않는다.

선택 문서 미리보기는 미저장 내용을 포함할 수 있고 상태/미저장을 표시한다. 전체 사이트 미리보기는 마지막 성공 빌드임을 구분한다. 공개와 같은 변환/템플릿을 사용하되 로컬에서 보인다고 공개 적합한 것은 아니다. 공개 불가능한 링크 등은 진단을 표시한다. 미리보기는 원본 저장·공개 전환·배포를 실행하지 않는다.

### 7.4 미디어·빌드·배포

미디어는 가져오기·목록·미리보기·파일/유형/크기 확인·대체 텍스트/캡션·공개 상태·본문 삽입·사용/미사용/미등록 확인을 지원한다. 사용 중 삭제와 이름 충돌·허용하지 않은 파일을 안내한다. 미사용을 자동 삭제하지 않는다.

빌드는 검증/진행/성공·오류·경고를 표시하고 관련 파일의 프로젝트 상대 위치·ID·항목·가능한 수정 방법을 알려준다. 비밀/민감 절대 경로는 노출하지 않는다. 실패 빌드를 배포 가능으로 표시하지 않는다. 상세 진단은 로컬 관리 정보이며 공개 파일에 넣지 않는다.

인증은 Git 설치·gh 설치·인증·`main` 접근/쓰기 권한·Actions workflow·Pages environment 상태를 구분한다. 미설치/미인증이면 안내하고 자격 증명을 입력받지 않는다. 배포 화면은 다음을 한 확인 흐름에서 구분해 보여준다.

- `main`에 저장할 `project/content`, `project/media`, `project/config` 변경과 자동 제외된 프로그램/문서 변경
- 새/수정/삭제 공개 파일, `draft`·`private` 제외 건수와 비공개 유입 검사
- 저장소 `biwoom/borido`, `main`, 커밋 후보와 Pages URL/접두사
- 원본 커밋·푸시 후 정확한 커밋으로 수동 Actions Pages workflow를 실행한다는 사실

최종 `원본 저장 및 배포` 확인 전에는 Git/원격/Pages를 바꾸지 않는다. 승인 후 입력·결과·원격 `main`이 바뀌면 재검토한다. `gh-pages` 브랜치를 표시하거나 관리하지 않는다. 원본 푸시 성공/Actions 실패처럼 부분 성공을 구분하고 이전 정상 사이트가 유지됨을 안내한다. 오류/권한/충돌/네트워크/workflow/Pages 실패별 조치와 복구를 제공한다.

## 8. 화면 완료 판정

공개 화면은 W17–W22, 편집기는 W23–W27, 인증/배포는 W28–W31에 연결한다. 모든 화면은 정상 자료 외에 빈 자료·긴 제목·없는 선택 정보·오류·키보드·모바일 상태를 확인한다. 사용자 원본을 직접 테스트하지 않고 격리된 자료를 사용한다. 수치/실제 기기/성능 검증이 남으면 그 항목을 완료로 표시하지 않는다.
