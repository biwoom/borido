## 1. 진행 방식과 단계 대응

이 계획은 기술 문서의 1–8단계를 유지하고 문서 준비를 0단계로 둔다. 기획 §13의 설계 단계, 데이터 §21의 모델 중심 단계, 편집기 §19의 6단계, 로드맵의 0–7단계와 번호를 직접 혼용하지 않는다. 각각의 요구는 아래 작업에 연결한다.

|단계|작업 범위|다음 단계로 가기 위한 증거|
|---|---|---|
|0. 착수 준비|P00–P02|충돌·결정 목록, 지침 초안 검토, 다음 단계 결정·fixture 정책|
|1. 프로젝트 기반|W01–W04|설정 생성/열기, 루프백 서버, 프로젝트 경계·초기화 보존 검증|
|2. 콘텐츠 Core|W05–W08|모델/검증/안전한 CRUD·참조·공개 상태 테스트|
|3. 경론 트리와 분류|W09–W10|독립 트리·검증된 분류 연결·이동 영향 검증|
|4. Markdown과 정적 생성기|W11–W16|실제 파일에서 공개 HTML·링크·미디어·검색 생성, 실패 빌드 보존|
|5. 공개 사이트 화면|W17–W22|탐색/독서·타 유형·검색/404·반응형·접근성 검증|
|6. 편집기 통합|W23–W27|한 경론의 편집→저장→미리보기→빌드→독서 흐름 재현|
|7. GitHub 인증·배포|W28–W31|로컬 배포 검증, 실제 전송은 승인된 대상에 한해 별도 확인|
|8. 통합 검증·안정화|W32–W34|원본 보호·복구·지원 환경에서 새 프로젝트 전체 흐름 재현|

기술 §13은 네 유형의 기본 모델을 2단계, 공개 화면을 5단계에 포함한다. 이 기본 계약은 먼저 마련하되, 복잡한 유형별 확장은 경론 한 편의 흐름을 확인한 뒤 진행한다. 경론 중심 검증이 다른 유형의 MVP 요구를 없애는 것은 아니다.

작업은 기능 하나/계약 하나/검증 목적 하나로 검토할 수 있도록 진행한다. 한 행에서 다룰 변경이 커지면 하위 작업으로 더 나누되, 선행 결정과 완료 기준을 그대로 연결한다. 모든 결정을 지금 한꺼번에 요구하지 않고 해당 구현 전에 필요한 D 항목만 해소한다.

단계 번호는 테스트를 마지막으로 미루라는 뜻이 아니다. W32의 로컬 회귀·보안 검증과 W33의 복구 절차 검증은 실제 배포 W31 전에 완료하고, W31 이후에는 실제 호스팅 결과를 추가 확인한다. W31은 별도 사용자 허용이 필요한 실행 단위다.

## 2. 공통 테스트 정책과 완료 판정

- **단위(U)**: 입력/출력·오류·경계 사례를 오프라인에서 검사한다.
- **통합(I)**: 격리된 임시 프로젝트에서 실제 파일 왕복·생성물·실패 후 상태를 검사한다.
- **브라우저(B)**: 로컬에서 실제 링크·입력·키보드·초점·뷰포트·JS 비활성을 확인한다. 도구/버전은 D01·D21에서 결정한다.
- **보안(S)**: 프로젝트 경계·악성 HTML/링크·비공개 자료·CLI 인자·자격 증명 비노출을 음성 사례로 검증한다.
- **수동(M)**: 실제 콘텐츠의 가독성, 운영체제 설치/인증, 승인된 호스팅의 동작을 기록한다. 자동 테스트와 구별한다.

완료 보고에는 변경 파일, 관련 요구/결정 ID, 실행 명령·환경·결과, 미실행 항목과 이유, 남은 문제를 남긴다. 동작 계약이 미정이면 기대 결과를 임의로 정해 테스트를 작성하지 않는다. 의존 결정이 남거나 필수 검증이 실패하면 해당 작업은 완료로 표시하지 않는다.

현재 `package.json`과 도구가 없어 아래 검증은 **예정 기준**이다. 기술 문서의 `npm run validate/build`, `npm test`, `npm run test:e2e`는 W01에서 스크립트와 실제 구현이 연결되기 전 실행 가능한 명령으로 취급하지 않는다. 실행을 하지 않은 검증을 통과라고 보고하지 않는다.

### fixture에 포함할 사례

P02에서 정책을 정하고, 최종 스키마가 결정된 뒤 각 작업에서 fixture를 만든다.

- 서로 다른 깊이의 번역·원문·연구와 구조/문서/개요, 같은 `order`, 빈 노드, 긴 제목·한글/한자/팔리어, 긴 표/각주.
- `draft`·`private`·`published`와 상태 누락/오류, 비공개 조상 아래 공개 자식, 비공개 문서의 고유 제목·경로·본문·미디어 표식.
- 중복 ID·URL, 분류/경론의 동일 slug, 경로 탈출·심볼릭 링크, 잘못된 JSON, 누락 파일·분류·문서·앵커·미디어, 리디렉션 순환/연쇄.
- 공개·비공개 문서가 공유하는 미디어, 비공개 전용 미디어, 공통 자산, 본문/각주/메타데이터의 미디어 참조.
- 원격 서비스 없는 기본 테스트 프로젝트. 실제 경론은 출처/사용 범위가 확인된 격리 자료를 사용하고 미검증 분류를 운영용으로 표시하지 않는다.
