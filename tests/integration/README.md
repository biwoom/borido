# Integration tests

격리된 임시 사용자 프로젝트의 실제 파일 왕복과 빌드·복구 동작을 검증한다. 운영 콘텐츠를 fixture로 사용하지 않는다.

W05 fixture는 저장소 안의 합성 원본을 임시 외부 경로에 복제해 검사한다. 읽기 전용 검증은 정상·오류·CLI 실행 전후 전체 파일 해시가 같아야 한다.

W06 저장 검사는 임시 프로젝트에서 UTF-8/줄바꿈, 리비전 충돌, 동시 요청, 합성 중간 실패/롤백, 완료 작업 복구와 후속 변경 보호를 확인한다. 저장소의 실제 `project/`는 제품 검증 대상으로만 읽고 실패 주입 fixture로 사용하지 않는다.

W08 CRUD 검사는 임시 프로젝트에서 경론·이야기·블로그·페이지 생성, 메타데이터/본문 리비전 수정, ID/slug 불변, 관련 콘텐츠 참조, 삭제 영향·참조 차단·삭제 ID 보존과 전체 경론 폴더 복원을 확인한다.

W10 트리 변경 검사는 임시 프로젝트에서 구조/본문 생성·리비전 정렬, 같은/다른 영역 이동의 URL 영향, 자기 하위 이동, 참조된 삭제, 삭제 URL 재사용, 합성 중간 실패 롤백과 이동/삭제 복원을 확인한다.

W11 Markdown 검사는 다국어/수동/중복 제목 앵커, 각주 정의와 반복 왕복, 내부 문서/자산 토큰, 원본 HTML·위험 프로토콜·외부 이미지 차단과 원본 불변을 확인한다.

W12 URL 검사는 네임스페이스/예약 slug·출력 충돌, 루트/저장소 접두사·도메인, 공개 ID/앵커 Markdown 링크, URL 이력의 직접 리디렉션·중복/현재 충돌/비공개·삭제 대상과 원본 불변을 확인한다.

W13 미디어 검사는 공개 본문·각주·대표·공통 자산의 합집합과 공유 1회 선별, 비공개 전용 제외, 없는/비공개 자산, 이미지 위치 PDF, 미등록/미사용 파일, 확장자·magic bytes·크기 한도와 파일 이동 후 UUID URL 안정을 확인한다. 실제 출력 복사는 하지 않는다.

W15 빌드 검사는 격리 프로젝트의 전체 정적 생성과 원본 해시, 공개 검색 결과, 비공개 `.borido` manifest, 생성 오류·반영 직전 입력 변경·백업 뒤 실패에서 이전 `dist/` 보존/복원을 확인한다.
